## hands

A piano player.

<img src="https://raw.githubusercontent.com/danielrigler/hands/refs/heads/main/screenshot.png">

A simple script which outputs MIDI notes to use with an external synth. 
I have used Claude to help with coding. 

### Controls
|||
|---|---|
| `E1` | Page |
| `E2` `E3`  | The Two Dials |
| `K2` | Vary |
| `K3` | New Piece |
| `K1`+`K2` | Run / Stop |
| `K1`+`K3` | Randomize All |

### Install
```
;install https://github.com/danielrigler/hands
```
